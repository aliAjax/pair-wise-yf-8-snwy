# 胶片分镜条核对台

一个纯前端本地应用，用来整理纸质放映胶片片段、拖拽调整放映顺序、统计总时长、筛选颜色偏移并生成试映前破损提醒。

内置双机换片接续表：在相邻可放映片段之间登记重叠秒数与信号距片尾秒数（重叠超过较短片段、或信号离片尾比重叠近时不保存）；拖动、筛选或删段后不再相邻的接续自动标记失效，导出清单会写出每处重叠秒数。接续判定（`changeover.js`）、保存（`changeoverStore.js`）与页面交互（`changeoverUI.js`）分文件维护，接续表随 localStorage 持久化，重开页面自动恢复。

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。
