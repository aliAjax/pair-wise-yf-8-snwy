# 胶片分镜条核对台

一个纯前端本地应用，用来整理纸质放映胶片片段、拖拽调整放映顺序、统计总时长、筛选颜色偏移并生成试映前破损提醒。

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。

## 双机接续表

在放映顺序下方的「双机接续表」里，从当前相邻且可放映（未标注「需跳过」、且通过筛选可见）的片段之间选择接续点，登记：

- **重叠秒数**：双机换片时两段画面重叠的时间；
- **片尾信号距片尾秒数**：片尾换片信号距离本段片尾的时间。

登记会经过两条校验，任一不满足则不保存，原接续表与片段顺序都不变：

1. 重叠不能超过两个片段中较短一个的时长；
2. 信号距片尾不能比重叠更近（否则看到信号时已来不及换片）。

拖动调序、上移下移、筛选或删除片段后，不再相邻的接续会自动失效并从接续表移除。导出清单会按放映顺序写出每处有效接续的重叠秒数和信号距片尾秒数。

## 文件结构

- `splice.js`：接续判定模块（纯函数）。负责可放映判定、相邻接续点计算、登记校验、失效筛选，不接触 DOM 与存储。
- `splice-store.js`：接续保存模块。负责接续表的 localStorage 读取、写入、删除与失效清理落盘。
- `app.js`：页面交互。负责片段录入/调序/筛选等既有功能，以及接续表单、列表和导出的渲染与事件。

片段数据保存在 `localStorage` 键 `zfl17-film-strip-desk`，接续表单独保存在 `zfl17-film-strip-desk-splices`，重开页面后均可恢复。
